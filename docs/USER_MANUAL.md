# YAGUBU 사용자 매뉴얼

**YAGUBU**는 야구 동호회를 위한 팀 홈페이지입니다. 팀 소개, 공지·일정, 기록, 커뮤니티, 갤러리를 한곳에서 관리하고 볼 수 있습니다.

## 1. 시작하기

- 브라우저에서 YAGUBU 홈페이지 주소로 접속합니다.
- **로그인하지 않아도** 팀 소개, 공지, 일정, 기록, 커뮤니티 글·갤러리 **보기**는 가능합니다.
- **글쓰기, 수정, 삭제** 등은 로그인 후 가능하며, 일부 기능은 **스텝(감독/코치/총무/관리자)** 권한이 필요합니다.

## 2. 화면 구성

### 상단 네비게이션

| 항목 | 설명 |
|------|------|
| **YAGUBU** | 로고 (클릭 시 상단으로) |
| **팀 소개** | 팀 연혁·비전, 선수단 구성 |
| **기록 및 일정** | 시즌 기록·일정 카드로 이동 |
| **커뮤니티** | 커뮤니티 섹션으로 이동 |
| **갤러리** | 팀활동 갤러리로 이동 |
| **🌙 버튼** | 다크 모드 / 라이트 모드 전환 |
| **로그인** | 로그인 모달 열기 (로그인 후에는 사용자 표시) |

### 메인 영역 (위에서 아래 순서)

1. **팀 소개** – 창단 스토리, 팀 가치, 연혁, 선수단
2. **상단 3개 카드** – 최신 공지, 다음 경기 일정, 최근 미디어
3. **슬로건 배너** – 팀 슬로건
4. **시즌 기록 및 일정** – 리그별 경기일정·팀기록·개인기록·투수기록
5. **시즌 전적** – 승률·승/패/무
6. **커뮤니티** – 게시글 목록
7. **팀활동 갤러리** – 사진/동영상 그리드

## 3. 로그인

우측 상단 **로그인** 버튼을 누르면 로그인 창이 열립니다.

### 일반 회원

- **성명**: 본인 이름
- **전화번호 뒤 4자리**: 예) 1234
- 입력 후 **확인**을 누르면 로그인됩니다.

### 관리자(스텝) – Supabase 사용 시

- 사이트가 **Supabase**로 설정된 경우, **이메일**과 **비밀번호** 입력란도 표시됩니다.
- 관리자는 **이메일 + 비밀번호**로 로그인할 수 있습니다.

### 로그인 후

- 상단에 로그인한 사용자 정보가 표시됩니다.
- 권한에 따라 **✏️(등록)·수정·삭제** 버튼이 보이거나, 글/갤러리에서 본인 것만 수정·삭제할 수 있습니다.

## 4. 팀 소개

팀 소개 영역에는 **탭** 두 개가 있습니다.

### 4.1 팀 연혁 및 비전

- **창단 스토리**: 팀이 어떻게 만들어졌는지 (스텝만 등록/수정 가능)
- **팀이 추구하는 가치**: 팀의 가치·비전 (스텝만 등록/수정 가능)
- **연혁**: 연도별 연혁 (스텝만 등록/수정 가능)
  - **MORE**: 연혁 전체보기. 행 **더블클릭** 시 해당 항목 수정

각 블록 오른쪽 **✏️** 버튼으로 등록/수정할 수 있습니다 (권한 필요).

### 4.2 선수단 구성

- **등번호, 성명, 스텝여부, 주포지션, 부포지션, 탈퇴여부, 연락처** 테이블
- **✏️**: 선수 등록 (스텝만)
- **MORE**: 선수단 전체 목록. 행 **더블클릭** 시 해당 선수 수정

**스텝여부** 예: 관리자, 감독, 코치, 총무, 선수

---

## 5. 최신 공지

- 최신 공지가 카드 형태로 표시됩니다.
- **✏️**: 공지 등록 (스텝만)
- **MORE**: 전체 공지 목록
  - **기간** (시작일 ~ 종료일) 선택 후 **조회**로 검색
  - 목록에서 항목 선택 후 **선택 삭제** 가능 (스텝만)

### 공지 등록 시

- **제목**, **등록일**, **내용** 입력 후 **저장**
- 수정 시 해당 공지를 연 뒤 **수정** 또는 삭제 후 재등록

---

## 6. 다음 경기 일정

- 다가오는 경기 일정이 표시됩니다.
- **✏️**: 경기 일정 등록 (스텝만)
- **MORE**: 전체 경기 일정
  - **리그**, **기간**으로 필터 후 **조회**

### 경기 일정 등록 시

- **리그**: 노노리그 / 동국대리그
- **경기일**, **경기 시간**, **상대팀**, **구장**, **진행여부**(예정/진행중/완료)
- **선공/후공**
- **진행여부**가 "완료"이면 **승패**, **스코어(우리:상대)** 입력 가능

---

## 7. 최근 미디어

- 최근 등록된 미디어(사진/동영상/유튜브)가 그리드로 표시됩니다.
- **✏️(📷)**: 미디어 등록 (로그인 회원)
- **수정**: 선택한 미디어 수정 (갤러리에서 항목 선택 후 활성화, 본인 또는 스텝만)
- **MORE**: 미디어 전체 목록·필터

**유형**: 동영상, 사진, 유튜브 중 선택 후 제목·내용·파일 또는 URL 입력

---

## 8. 시즌 기록 및 일정

상단 **리그** 드롭다운에서 **전체 / 노노리그 / 동국대리그**를 선택하면 아래 탭 내용이 해당 리그 기준으로 바뀝니다.

### 8.1 경기일정 탭

- **날짜/시간, 대전, 구장, 성적, 간시** 테이블
- **✏️**: 경기 일정·승패 등록 (스텝만)
- **MORE**: 시즌 경기 일정 전체

### 8.2 팀기록 탭

- **팀 기록실**: 팀 타율, 팀 방어율, 최근 전적
- **타율/안타/타점/도루** 순위표 (등번호, 성명, 수치)

### 8.3 개인기록 탭

- **등번호, 성명, 타석, 타수, 안타, 타점, 득점, 사사구, 삼진, 도루, 타율** 테이블
- **✏️**: 개인기록 등록 (스텝만)
- **MORE**: 개인기록 전체. **행 더블클릭** 시 상세 확인 및 수정

개인기록 입력 시 **타율·타점(자동)** 은 자동 계산됩니다.

### 8.4 투수기록 탭

- **등번호, 성명, 이닝, 피안타, 자책점, 승, 패, 세이브, 방어율** 테이블
- **✏️**: 투수기록 등록 (스텝만)
- **MORE**: 투수기록 전체. **행 더블클릭** 시 수정

**방어율**은 자동 계산됩니다.

---

## 9. 커뮤니티

- 팀원이 올린 글이 목록으로 표시됩니다.
- **✏️**: 글쓰기 (로그인한 회원)
- **MORE**: 기간으로 조회한 전체 글 목록

### 글 보기

- 목록에서 글을 클릭하면 **상세 보기** 모달이 열립니다.
- **댓글** 작성 (로그인 회원)
- **좋아요** (하트 버튼)
- **수정 / 삭제**: 작성자 또는 스텝만 가능

### 글쓰기 시

- **제목**, **작성일**, **작성 시간**, **내용**, **작성자** 입력 후 저장

---

## 10. 팀활동 갤러리

- 사진·동영상이 그리드로 표시됩니다.
- **앨범**, **태그** 드롭다운으로 필터링 가능.
- **✏️(📷)**: 사진/미디어 등록 (로그인 회원)
- **MORE**: 전체 갤러리 (앨범·태그 필터 사용)

### 사진 보기

- 썸네일 클릭 시 **상세 보기** (제목, 메타, 설명, 이미지).
- **수정 / 삭제**: 등록자 또는 스텝만 가능.

### 사진 등록 시

- **앨범** 선택 또는 새로 입력
- **태그** (쉼표로 구분)
- **제목**, **날짜**, **시간**, **한줄 설명**, **내용**
- **사진 파일** 선택 또는 **URL** 입력 (유형에 따라)

## 12. 기타 기능

### 다크 모드

- 상단 **🌙** 버튼으로 **라이트/다크** 테마를 전환할 수 있습니다.
- 선택한 테마는 브라우저에 저장되어 다음 접속 시에도 유지됩니다.

### MORE / 전체보기

- 각 섹션의 **MORE** 링크는 해당 항목의 **전체 목록** 또는 **기간·필터 조회** 모달을 엽니다.
- 테이블에서 **행 더블클릭** 시 수정 모달이 열리는 경우가 많습니다 (개인기록, 투수기록, 선수단, 연혁 등).

### 모바일에서 사용하기

- YAGUBU는 반응형으로 제작되어 휴대폰·태블릿에서도 이용할 수 있습니다.
- 자세한 모바일 대응 방법은 **docs/MOBILE_VERSION_GUIDE.md**를 참고하세요.
